# Text Reader Extension – Installation Guide

## Install the Extension in Google Chrome

Follow these steps to install the extension locally in Chrome:

1. Download or extract the extension folder to your computer.
2. Open Google Chrome.
3. In the address bar, type:
   `chrome://extensions`
4. Turn ON **Developer mode** (top-right corner).
5. Click **Load unpacked**.
6. Select the extension folder you downloaded/extracted.
7. The extension will now appear in your Chrome extensions list.
8. Pin the extension from the Extensions icon for quick access.

## How to Use

1. Open any webpage or PDF in Chrome.
2. Highlight the text you want to hear.
3. The extension will read the selected text aloud.
4. Use the extension popup/settings to:

   * Turn ON/OFF the reader
   * Change voice
   * Adjust reading speed

Enjoy your text-to-speech browsing experience!
